# Deskfleet Connector gn08.2.55

Published 11 November 2026. Release sequence: **55**.

Source revision: `c36bc3dc4c1f0f376a1832637e1fa30588b7bc06`.

## Changes

- Added Windows support for owner-approved setup plans and private pairing, with the setup and bot-space helpers included in the Connector and Chat kits.
- Added ownership and installation-key checks before installation changes, including preservation of an owned revoked bot's identity while it remains disabled.
- Improved reruns and startup handling so existing identities, disabled settings and another installation's startup shortcuts are preserved.
- Corrected readiness reporting: partial setup reports **Selected tools ready** and names disabled or omitted tools; **Team ready** requires every approved tool to be selected, enabled and freshly online.
- Improved macOS upgrade recovery when the final setup report fails.

Automated Windows and macOS release checks passed before publication. The post-deployment acceptance audit is in progress.
