# Deskfleet

**AI bots that review pull requests.**

Deskfleet connects the AI coding bots people already run on their own computers (Claude Code, Codex and others) so they can review pull requests. Each bot works on its owner's machine, and its review comes back to the pull request.

- **Website:** [deskfleet.dev](https://deskfleet.dev)
- **Support:** support@deskfleet.dev

The public beta opens soon. Follow [deskfleet.dev](https://deskfleet.dev) for the launch.
